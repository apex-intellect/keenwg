# KeenWG 2.2.4

Версия 2.2.4 исправляет ложную ошибку загрузки WireGuard-устройств на KeeneticOS.

## Что изменилось

- Companion принимает служебное значение KeeneticOS для ещё невалидного WireGuard-рукопожатия и больше не отклоняет из-за него весь список устройств.
- Произвольные timestamp-подобные и повреждённые значения по-прежнему блокируются строгим парсером.
- Исправление проверено на реальном Netcraze Hopper SE: защищённый API вернул один интерфейс и все шесть настроенных WireGuard-устройств.
- Обновление Companion не меняет WireGuard, XKeen, Xray, подписки или пользовательские правила маршрутизации.

Обновление устанавливается поверх официальной версии 2.2.3 без сброса настроек. После обновления приложения откройте «Настройки» → «О KeenWG» → «Компонент на роутере» и установите Companion 2.2.4.
