# Управление XKeen из KeenWG 0.4

KeenWG подключается к отдельному контроллеру на роутере и получает только очищенные данные: название узла, страну, флаг, публичный адрес, порт и состояние операции. VLESS-ссылка, UUID, Reality public key, short ID, SNI, пароль root и SSH-ключ через Android API не передаются.

## Настройка

1. Установите контроллер по инструкции в [`xkeen-control/README.md`](../xkeen-control/README.md).
2. Откройте настройки KeenWG и найдите раздел «XKeen».
3. Укажите адрес, например `http://10.8.0.1:18778`, и отдельный токен контроллера. Не используйте здесь токен сборщика истории.
4. Нажмите «Проверить контроллер». Успешная проверка подтверждает одновременно доступность API и правильность токена.
5. Нажмите общую кнопку «Сохранить и проверить».

HTTP разрешён только для приватных и CGNAT IPv4-адресов. Для имени хоста или публичного адреса используйте HTTPS. Не публикуйте порт контроллера в WAN.

## Ручное обновление и выбор страны

Кнопка «Управление XKeen» на главном экране открывает текущий маршрут и список узлов. Открытие экрана выполняет только чтение статуса. Оно никогда не обновляет подписку автоматически и не меняет активный узел.

- «Обновить подписку» вручную загружает актуальный список с сервера, но сохраняет текущий активный узел.
- Нажатие на неактивный узел открывает подтверждение с направлением переключения.
- Узлы одной страны не объединяются: каждый сервер выбирается отдельно.
- Предупреждение о fingerprint `chrome` видно до переключения, но не блокирует ручной выбор.

## Результаты операции

- `success` — новый узел применён, проверка доступа в интернет пройдена.
- `failed_rolled_back` — переключение не прошло проверку, прежний узел восстановлен.
- `failed_no_change` — контроллер не применял изменений.
- `uncertain` — итог нельзя подтвердить. Новые изменения блокируются до следующего достоверного статуса.

Если связь пропала после отправки команды, KeenWG не повторяет переключение. Приложение опрашивает уже созданную операцию до терминального результата или ограниченного тайм-аута.

## Разделение сервисов

Контроллер XKeen и сборщик истории WireGuard — независимые сервисы с разными адресами, портами и токенами. Недоступность одного не должна мешать работе другого. Секреты сохраняются в зашифрованном хранилище приложения и не помещаются в навигацию, логи или текст ошибок.
