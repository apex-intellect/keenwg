# KeenWG 2.1.1

Исправление установки и обновления защищённого доступа на Keenetic.

## Что исправлено

- Передача роутерного компонента больше не требует SFTP, которого нет в стандартной конфигурации SSH на ряде Keenetic.
- Архив и запрос установки передаются бинарным потоком через обычный SSH-канал с закрытыми правами временных файлов.
- Для обновления не нужно устанавливать на роутер дополнительные пакеты или менять настройки SSH.

## Обновление

Установите APK 2.1.1 поверх версии 2.1.0 и повторите настройку роутера. Неудачная попытка из 2.1.0 останавливалась до установки и не меняла XKeen, Xray, ASC, WireGuard или маршрутизацию.

Встроенный Companion имеет версию 2.1.1; его серверная логика в этом хотфиксе не менялась.
