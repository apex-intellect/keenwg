# Настройка Companion

Companion — локальная часть KeenWG на роутере. Она даёт приложению защищённый API для XKeen/VLESS, маршрутов, сценариев, диагностики, backup и доверенных устройств. Subscription URL, VLESS URI и приватные параметры Xray остаются на роутере.

## Требования

- поддерживаемый ARM64 Keenetic/Netcraze с Entware;
- XKeen/Xray для функций подключения и маршрутизации;
- SSH-доступ к роутеру из текущей сети;
- свободный приватный IPv4-адрес роутера для HTTPS `18779`.

Точная подтверждённая конфигурация находится в [COMPATIBILITY.md](COMPATIBILITY.md).

## Установка из приложения

1. Создайте или выберите профиль роутера.
2. Откройте «Система» → «Установить или обновить Companion».
3. Укажите SSH-адрес, порт и пользователя.
4. Получите fingerprint и сравните его с доверенным источником.
5. После подтверждения введите временный SSH-пароль. Он не сохраняется в профиле.
6. Проверьте read-only отчёт: архитектуру, firmware, Entware, XKeen/Xray и выбранный режим.
7. Отдельно подтвердите действие.

Мастер выбирает один из режимов:

- `CLEAN_INSTALL` — Companion ещё отсутствует;
- `UPDATE` — установлена более ранняя версия;
- `PAIR_ONLY` — актуальный Companion уже работает, поэтому приложение только привязывает телефон.

Установка и обновление сначала проверяют новый процесс и HTTPS health. При ошибке активная версия восстанавливается. Очистка устаревшего самостоятельного сервиса выполняется только после успешной проверки 2.0.

## Pairing

Телефон получает URL, certificate pin и одноразовое owner-приглашение по уже подтверждённому SSH-каналу. Обмен выполняется по HTTPS с exact pinning. Затем приложение запрашивает capabilities и сохраняет собственный device token в Android Keystore.

Повторная установка для восстановления телефона не нужна: запустите мастер снова. При работающем Companion 2.0 он выберет `PAIR_ONLY` и не загрузит бинарник.

## Подписка и выбор страны

Источник можно добавить в разделе «Подключения»: вставьте VLESS URI или subscription URL, проверьте preview и подтвердите сохранение. Исходная строка отправляется Companion и не возвращается в каталог Android.

Обновление подписки, тест узла и активация выполняются только по нажатию пользователя. Выбор узла требует свежего успешного теста и отдельного подтверждения. Если результат нельзя доказать, новые изменения блокируются до read-back.

## Модули

- Companion: подключения, маршруты, сценарии, trusted devices, backup и diagnostics.
- RCI: WireGuard peer и статические адреса. Настраивается независимо.
- Collector: необязательная история WireGuard. Его недоступность не блокирует остальные разделы.

## Восстановление

- Изменился SSH host key: не подтверждайте его, пока не установите причину.
- Изменился certificate pin: запустите pairing через подтверждённый SSH; не отключайте проверку TLS.
- Результат операции `uncertain`: не редактируйте state вручную, обновите экран и используйте предложенный recovery.
- Companion не запускается после update: installer должен восстановить предыдущий release; скопируйте только санитизированный отчёт.

Не публикуйте SSH-пароль, pairing secret, device token, subscription URL, VLESS URI, router backup или полный отчёт без проверки.
