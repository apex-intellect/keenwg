# Настройка защищённого доступа

Companion — внутреннее имя локальной части KeenWG на роутере. В пользовательском интерфейсе она называется «защищённый доступ». Через неё приложение управляет XKeen/VLESS, маршрутами, домашними устройствами, статическими DHCP-адресами, WireGuard-доступами, сценариями, диагностикой, резервными копиями и доверенными телефонами. Subscription URL, VLESS URI и приватные параметры Xray остаются на роутере.

## Что должно быть установлено заранее

- поддерживаемый ARM64 Keenetic/Netcraze;
- Entware и доступное хранилище `/opt`;
- XKeen/Xray для подключений и маршрутизации;
- телефон в доверенной локальной сети роутера;
- логин и пароль, с которыми устанавливались XKeen/Entware (обычно `root`, порт `222`).

KeenWG не форматирует накопитель, не создаёт разделы и не устанавливает Entware или XKeen. Entware нужен для установки или обновления защищённого компонента. Небольшой системный клиент `ndmq` устанавливается через `opkg` автоматически, только если его ещё нет, и до переключения активной версии Companion. XKeen остаётся необязательным: без него не появятся только связанные с ним подключения и маршруты. Если Entware не найден, приложение показывает причину, открывает [инструкцию XKeen](https://github.com/Corvus-Malus/XKeen) и позволяет повторить проверку.

Точная подтверждённая конфигурация находится в [COMPATIBILITY.md](COMPATIBILITY.md).

## Установка из приложения

1. Откройте «Система» → «Подключение к роутеру».
2. Один раз введите адрес, логин и пароль доступа. Новый профиль предлагает адрес `192.168.1.1`, логин `root` и порт `222`.
3. KeenWG получает публичную идентичность роутера без отправки пароля. При первом подключении она сохраняется только после полностью успешной настройки. Если сохранённая идентичность изменилась, приложение останавливается до авторизации и просит отдельно подтвердить, что роутер действительно был сброшен или заменён.
4. Тем же временным буфером пароля приложение выполняет read-only проверку и, если всё готово, установку/обновление и привязку телефона. Повторного ввода нет.
5. После успешной проверки пароль стирается из памяти. Адрес первичной настройки, идентичность роутера, HTTPS pin и собственный отзываемый токен телефона сохраняются одной транзакцией; адрес Keenetic API при этом не меняется.

Во время операции мастер сохраняет существующие XKeen, Xray, ASC, WireGuard, подписки и пользовательские правила. Возможны три внутренних режима:

- `CLEAN_INSTALL` — роутерный компонент KeenWG отсутствует;
- `UPDATE` — версия устарела либо хеш бинарника не совпадает с проверенным комплектом;
- `PAIR_ONLY` — актуальный проверенный компонент уже работает, поэтому добавляется только этот телефон.

Если компонент на роутере новее встроенного в приложение, мастер останавливается и просит обновить KeenWG. Неизвестная будущая версия не считается совместимой автоматически.

Установка и обновление используют staging, проверку SHA-256, HTTPS health и атомарное переключение. При подтверждённой ошибке активная версия восстанавливается. Если результат нельзя доказать, приложение блокирует новые изменения и предлагает безопасный отчёт.

## После подключения

- Обновление подписки, тест узла и выбор страны запускаются только вручную.
- Личную ссылку подписки можно добавить или заменить в «Связи». Она хранится только на роутере и не возвращается приложению; текущая выбранная страна при обновлении списка не меняется.
- Выбор узла требует свежего успешного теста и отдельного подтверждения.
- Домашние устройства, статические адреса и существующие WireGuard-доступы доступны через тот же токен телефона: логин и пароль Keenetic API повторно не запрашиваются.
- Если штатный Collector установлен на роутере, Companion автоматически отдаёт его историю по тому же защищённому доступу. Адрес и Collector token в приложение не вводятся и на телефоне не хранятся.
- Новый приватный WireGuard-ключ создаётся на телефоне и не передаётся Companion; роутер получает только публичный ключ.
- Доверенный телефон можно отозвать в разделе «Доверенные устройства».
- Повторная установка для восстановления телефона не нужна: мастер выберет `PAIR_ONLY`, если проверенный компонент уже работает.
- Обновления версии 2.2.0 и новее устанавливаются через «О KeenWG» → «Компонент на роутере» без повторного пароля. Официальный архив проверяется издательской подписью, после установки — HTTPS health и ожидаемой версией. Для перехода со старой версии пароль понадобится один последний раз.

## Независимые модули

- Защищённый доступ: домашние устройства, статические адреса, WireGuard, доверенные телефоны, backup, diagnostics и локальный шлюз для доступных модулей.
- XKeen/Xray: необязательные подключения, страны, маршруты и сценарии.
- Keenetic API (RCI): только legacy-путь для старого профиля без Companion; после подключения Companion не нужен.
- Collector: необязательное локальное хранилище истории WireGuard на роутере; Companion является единственным шлюзом для телефона, а отсутствие Collector не блокирует остальные разделы.

## Восстановление

- Идентичность роутера изменилась: продолжайте только после собственного сброса/замены роутера и в доверенной локальной сети.
- Pin HTTPS изменился: снова запустите «Подключение к роутеру»; не отключайте проверку TLS.
- Результат операции неопределён: не редактируйте служебные файлы вручную, обновите состояние и используйте предложенное восстановление.
- Компонент не запускается после обновления: сохраните только встроенный безопасный отчёт; установщик оставляет recovery-файлы при неподтверждённом результате.

Не публикуйте пароль, pairing secret, device token, subscription URL, VLESS URI, backup роутера или полный технический отчёт.
