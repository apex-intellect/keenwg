# KeenWG 2.2.0

Версия 2.2.0 убирает повторный ввод пароля из обычной работы и делает названия действий однозначными.

## Главное

- Ссылка XKeen-подписки добавляется и меняется прямо в «Связях». Она хранится только на роутере и не возвращается телефону.
- Кнопка «Обновить XKeen» заменена на «Загрузить свежий список». Действие обновляет страны и серверы, но не переключает текущий маршрут.
- Обычные настройки больше не ведут к ручным параметрам и повторному вводу пароля. Технические поля доступны только после явного включения экспертного режима в «О KeenWG».
- Роутерный компонент обновляется из приложения без пароля. Архив подписан Ed25519-ключом Apex Intellect, проверяется до установки и автоматически откатывается при неуспешном health check.
- Первый переход с 2.1.x требует один последний вход по паролю, потому что прежний компонент ещё не поддерживает защищённый канал обновлений.

## Интерфейс

- Разделы называются «Обзор», «Связи», «Маршруты», «Доступ» и «Система».
- Добавлены отдельные состояния передачи, установки, переподключения, успешного обновления и подтверждённого отката.
- Ошибки подписки и обновления не содержат URL, токены, подписи и пути роутера.

Установите APK поверх 2.1.2. Затем откройте «Система» → «О KeenWG» → «Компонент на роутере» и выполните единственный переходный апдейт. Настройки XKeen, Xray, ASC, WireGuard, выбранная страна и доверенные телефоны сохраняются.
