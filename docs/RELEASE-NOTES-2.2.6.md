# KeenWG 2.2.6

Патч-релиз упрощает добавление нового WireGuard-устройства: KeenWG больше не просит вручную вводить технический адрес домашнего VPN.

## Что изменилось

- Приложение автоматически определяет внешний IP-адрес роутера и фактический порт выбранного WireGuard-интерфейса через KeenOS.
- Убрано дополнительное окно «Адрес для нового устройства» и повторный ручной ввод параметров.
- Уже сохранённый корректный адрес остаётся без изменений.
- Если адрес определить не удалось, приложение показывает понятное сообщение и не изменяет настройки роутера.
- Добавлены тесты автоматического определения адреса и создания доступа.

Обновление устанавливается поверх официальной версии 2.2.5 без сброса настроек и не требует отдельного обновления Companion.
