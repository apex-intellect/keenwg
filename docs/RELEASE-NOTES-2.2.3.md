# KeenWG 2.2.3

Версия 2.2.3 исправляет готовые правила маршрутизации, ускоряет удалённый доступ и делает основные экраны заметно компактнее.

## Что изменилось

- «Наборы» больше не выглядят отдельной непонятной функцией: готовые правила для российских ресурсов, Okko и ЕМИАС находятся внутри раздела «Сайты» и показывают точные изменения перед применением.
- Исправлена несовместимость с Companion 2.2.1, который возвращал пустые условия готовых правил как `null`. Новый Companion всегда отдаёт однозначные массивы, а приложение корректно принимает и прежний ответ.
- Общая кнопка обновления в правилах теперь действительно повторяет загрузку готовых правил; локальная ошибка не скрывает уже работающие правила сайтов.
- Список WireGuard сначала показывает безопасно сохранённые данные, повторяет кратковременные сбои и не очищает экран из-за одного неудачного запроса.
- Companion кратко кэширует проверенный список WireGuard и сбрасывает кэш при любом изменении, поэтому переходы и обновления стали быстрее без риска показать устаревший результат после записи.
- VPN-серверы стали компактнее: результат проверки находится справа, активный сервер хорошо выделен, а действия подписки собраны в одну строку.
- Убраны лишние контуры и полупрозрачные прямоугольные слои внутри карточек.
- Экран настроек получил меньшие поля и высоту строк; выбор языка теперь занимает только необходимое содержимому место.

Обновление устанавливается поверх официальной версии 2.2.2 без сброса настроек. Companion обновляется безопасно через мастер подключения к роутеру.
