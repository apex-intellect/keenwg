# KeenWG 2.2.8

Версия 2.2.8 исправляет добавление пользовательских VPN-подписок и упрощает экран VPN-серверов.

## Что изменилось

- После добавления подписки KeenWG сразу загружает список серверов; отдельное скрытое обновление больше не требуется.
- Название подписки, использованный трафик, лимит и срок действия считываются из совместимых с HAPP `profile-title` и `subscription-userinfo`, если провайдер их передаёт.
- Новые метаданные выдаются только запросившему их клиенту: приложения предыдущих версий продолжают получать прежнюю схему каталога.
- Личная ссылка подписки больше не используется как видимое название. Если провайдер не передал имя, показывается только безопасное имя или домен без секретной части ссылки.
- Источники подписок собраны в один компактный список без больших карточек и лишнего начального скролла.
- Для неудачно загруженной подписки доступны явная повторная попытка и удаление с подтверждением.
- Исправлено повторное использование названия из предыдущего диалога добавления.
- Companion и Collector собираются Go 1.26.7 с актуальными исправлениями безопасности и `net/http`.

Для новых возможностей метаданных и загрузки пользовательских подписок установите APK и обновите «Компонент на роутере» до версии 2.2.8. Существующие XKeen, WireGuard, маршруты, подписки и доверенные телефоны сохраняются.
