# KeenWG 0.8.0 — каталог подключений

Версия 0.8.0 добавляет единый каталог подключений поверх XKeen, standalone sing-box и AWG Manager 2.16. С телефона можно вручную перечитать источник, проверить конкретный узел и только затем явно активировать его.

## Главное

- единый экран «Подключения» с группами, источниками и точными узлами;
- одинаковые страны не объединяются: каждый сервер остаётся отдельным вариантом;
- проверка доступности не меняет активный маршрут;
- результат проверки действует пять минут и сбрасывается при изменении каталога;
- активация выполняется по точному ID и подтверждается чтением фактического состояния;
- потеря ответа или ошибка сохранения показывается как неопределённое состояние без ложного успеха;
- старый экран XKeen остаётся fallback для профилей Companion 0.7;
- исходные ключи и учётные данные не попадают в каталог, ответы API или журналы.

## Совместимость

- XKeen/Xray: поддерживается;
- standalone sing-box Clash API: beta до проверки на физических конфигурациях;
- AWG Manager 2.16.5: beta до проверки на физическом роутере;
- Android: 8.0+.

Обновление и переключение остаются только ручными. Установка поверх 0.7 не должна менять активный маршрут; этот сценарий требует финальной проверки на телефоне владельца.
