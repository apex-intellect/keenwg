# KeenWG 2.2.2

Версия 2.2.2 делает обновление списка устройств WireGuard устойчивее и завершает переход на фирменную иконку Apex Intellect.

## Что изменилось

- При кратковременной недоступности Companion приложение повторяет загрузку списка WireGuard один раз автоматически.
- Единичный сбой фонового обновления больше не скрывает уже загруженные устройства и не показывает преждевременную ошибку.
- Если связь действительно пропала, повторные сбои по-прежнему отображаются; ошибки авторизации сразу предлагают переподключить телефон.
- Ручное обновление остаётся явным: если запрос не выполнен, пользователь сразу видит причину.
- Иконка приложения заменена на Apex Core; добавлен отдельный монохромный вариант для тематических значков Android.

Обновление устанавливается поверх официальной версии 2.2.1 без сброса настроек.
