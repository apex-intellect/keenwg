# KeenWG 2.2.10

## Исправления

- Подписки VLESS/REALITY поддерживают gRPC наряду с TCP/Vision. Companion сохраняет serviceName, authority и multiMode, формирует настройки Xray и корректно читает активный gRPC-узел.
- Главный экран Android принимает gRPC-узлы с пустым flow; смешанный список TCP/gRPC больше не вызывает ошибку схемы ответа.
- При конфликте версии каталога ответ содержит актуальный список. Если состояние XKeen изменилось отдельно, Companion синхронизирует каталог и предлагает повторить действие, вместо бесконечного «Список изменился».
- Обновление списка не переключает выбранный сервер. Конфликт не запускает скрытую активацию нового или заменённого узла.

## Безопасность сборки

- Компонент собран Go 1.26.11 с актуальными исправлениями стандартной библиотеки; golang.org/x/net обновлён до версии с исправлениями HTTP/2.
- Ошибка тестов, сканера уязвимостей или другой команды теперь немедленно останавливает выпуск.
- Для обычных Android-проверок CI загружает базовый Companion только с проверкой контрольной суммы и подписи издателя. В релиз включается заново собранный и подписанный Companion этой же версии.
- Выпуск 2.2.9 остановлен до публикации APK после обнаружения уязвимого инструмента сборки. Публичный тег сохранён для истории; используйте 2.2.10.

## Порядок обновления

1. Установите APK 2.2.10 поверх текущего приложения.
2. В разделе «Компонент KeenWG» обновите компонент на роутере до 2.2.10.
3. Обновите подписку, чтобы появился gRPC-узел.

Старый Android-клиент 2.2.8 не умеет отображать gRPC в сводке XKeen. Приватные параметры gRPC не добавляются в публичную схему API. Активный сервер автоматически не переключается.
