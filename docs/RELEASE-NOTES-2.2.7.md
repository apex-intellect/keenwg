# KeenWG 2.2.7

Версия 2.2.7 исправляет регрессию создания WireGuard-доступа из 2.2.6.

## Что изменилось

- Внешний адрес и порт WireGuard теперь получает защищённый компонент KeenWG на роутере, без повторного пароля и без устаревшего прямого входа в KeenOS.
- Создание нового устройства снова доходит до безопасных этапов проверки и применения изменений.
- Уже сохранённый корректный адрес остаётся приоритетным и не перезаписывается.
- Для определения адреса добавлен отдельный обратно совместимый API: формат существующего списка WireGuard не менялся и старые приложения не ломаются.
- Если на роутере стоит предыдущая версия компонента, приложение показывает одно понятное действие «Обновить компонент на роутере» вместо ложной ошибки подключения и бесконечного повтора.
- Автоопределение проверено на реальном ответе KeeneticOS 5.01 и покрыто регрессионными тестами Android и Companion.

После установки APK откройте «Настройки» → «Компонент KeenWG» и установите предложенное обновление 2.2.7. Настройки WireGuard, XKeen, маршруты и доверенные телефоны сохраняются.
