# KeenWG 2.2.9

## Исправления

- Подписки VLESS/REALITY теперь поддерживают gRPC наряду с TCP/Vision. Companion сохраняет serviceName, authority и multiMode, формирует настройки Xray и корректно читает активный gRPC-узел.
- Главный экран Android принимает gRPC-узлы с пустым flow; смешанный список TCP/gRPC больше не вызывает ошибку схемы ответа.
- При конфликте версии каталога ответ содержит актуальный список. Если состояние XKeen изменилось отдельно, Companion атомарно синхронизирует каталог и предлагает повторить действие, вместо бесконечного «Список изменился».
- Обновление списка не переключает выбранный сервер. Конфликт не запускает скрытую активацию нового или заменённого узла.

## Совместимость

Обновите приложение и Companion вместе: старый Android-клиент 2.2.8 не умеет отображать gRPC в сводке XKeen. Используйте подписанный комплект этой версии из штатного процесса выпуска. Приватные параметры gRPC не добавляются в публичную схему API.

## Проверки

Добавлены регрессионные проверки смешанных подписок TCP/gRPC, сохранения параметров, формирования и чтения конфигурации, публичной схемы без приватных параметров и восстановления после конфликтов каталога.
